State and Explain the components of a DBMS(Database Management System)
Hardware - Physical and electronic devices such as computers.
Software - Set of programs used to manage and control the database.
Data -Raw facts and information that need to be organized and processed to make it more meaningful.
Procedure -Instructions used in a database management system.
Database access language -Language used to write commands to access, updae and delete data stored in databases.

What is a relational database? Give 4 examples.
A relational database is a database that stores and provides access to datapoints that are related to one another.Examples include MySQL, Microsoft SQL server and Oracle database.

State and Explain three classifications of SQL?
Data Definition Language- They are used to define, modify, create and delete database structures such as tables, indexes and schemas.
Data Manipulation Language - Statements used to manipulate the data within existing database objects.Allows users to retrieve, insert, update and delete data.
Data Control Language - Statements that manage access to data within the database. They control permission and security levels for users and roles ensuring that only authorized persons can perfom specific operations on data.

What is the difference between a Primary Key and a Foreign Key?
A primary key is a unique identifier for each record in a table while a foreign key establishes a relationship between tables by referencing the primary key of another table

What is an Entity-Relationship Diagram?
Is a visual representation of how entities relate to each other in a system.

Efficient storage and retrieval of data by structural organization of data.
